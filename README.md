# HWHOneArenaBattle

Расширение для [HeroWarsHelper](https://greasyfork.org/ru/scripts/450693-herowarshelper) (HWH), которое проводит бои на **Арене** и **Гранд-Арене**, ведёт историю боёв в IndexedDB, считает вероятность победы и **автоматически подбирает лучшую пачку атаки** из накопленной статистики.

## Возможности

### Бои

- ⚔️ **Один бой на Арене** — берёт текущую пачку (герои + питомец + favor + флаг) и атакует первого подходящего соперника.
- 🛡️ **Один бой на Гранд-Арене** — три пачки, три флага, атака одного соперника.
- 🚫 **Фильтр дружественных гильдий** — не атакует согильдийцев и гильдии из вашего списка.
- 🔄 **Автопоиск соперника** — до 10 попыток обновления списка с паузой 1.5 сек.
- 🎚️ **Опциональный фильтр** — «атаковать только если не было атак за сегодня» (отдельно для Арены и ГА).
- 🎲 **Автосмена защиты ГА** — переставляет три пачки защиты Гранд-Арены в случайном порядке каждые 15 секунд (включается галочкой в настройках, автозапуск при загрузке игры).

### История боёв и автоподбор пачки

- 📚 **История боёв в IndexedDB** — каждый бой после атаки автоматически сохраняется (если вероятность ≥ 60%). Отдельные хранилища для Арены и Гранд-Арены.
- 🎲 **Симуляция вероятности** — 5 прогонов боя через `Calc` со случайным seed, результат — доля побед (`probability`).
- 🤖 **Автовыбор лучшей пачки** — перед атакой ищет в истории пачки, которые бились против текущего защитника, и выбирает с наибольшей средней `probability`.
  - **Точный матч** — защитник совпал по составу и питомцу.
  - **Фолбэк ≥ 80%** — 4 из 5 героев совпали и тот же питомец.
  - Для Гранд-Арены — подбирает до 3 пачек без пересечения героев.
- 💾 **Экспорт / импорт базы** — перенос истории между браузерами или ПК через единый JSON-файл (Арена + Гранд-Арена).
- 🔄 **Загрузка истории с сервера** — через `battleGetByType` подтягивает прошедшие бои (только ваши атаки), считает вероятность и сохраняет в БД. Уже обработанные реплеи запоминаются в `localStorage`, чтобы не пересчитывать при повторных запусках.
- 🧹 **Автоочистка** — записи старше 120 дней удаляются раз в сутки.

### Интерфейс

- Кнопки в меню **«Действия»**:
  - **Провести 1 бой на Арене**
  - **⚙️** — настройки авто-боя
  - **🌐** — дружественные гильдии
  - **📚** — история боёв (экспорт / импорт / загрузка с сервера)
  - **Провести 1 бой на Гранд-Арене**
- Галочки в форме **«Сделать всё»**: «Провести 1 бой на арене», «Провести 1 бой на Гранд-Арене».
- Прогресс и результат — в статусе HWH и в консоли браузера (F12). Живой таймер выполнения при импорте истории.

## Использование

### Бой через меню «Действия»

1. Откройте панель HWH.
2. Нажмите **«Действия»**.
3. Выберите **«Провести 1 бой на Арене»** или **«Провести 1 бой на Гранд-Арене»**.

### Бой через «Сделать всё»

1. Откройте панель HWH.
2. Нажмите **«Сделать все»**.
3. Поставьте галочки на нужных действиях.
4. Нажмите **«Погнали!»**.

### Настройки авто-боя (кнопка ⚙️)

- **Сохранять историю боёв (расчёт вероятности)** — включает запись боёв в IndexedDB.
- **При автоатаке искать лучшую пачку в истории боёв** — включает автоподбор пачки по `probability` (недоступно без сохранения истории).
- **Арена: атаковать только если не было атак за сегодня** — пропускает бой, если попытки уже тратились.
- **Гранд-Арена: атаковать только если не было атак за сегодня** — то же для ГА.
- **Не атаковать дружественные гильдии** — включает фильтр из списка 🌐.
- **ГА: автосмена защиты каждые 15 секунд** — периодически переставляет пачки защиты Гранд-Арены в случайном порядке.

### Дружественные гильдии (кнопка 🌐)

- Список всех гильдий из топ-лиг (кэш на 24 часа).
- Отметьте галочками те, которые не нужно атаковать.
- Кнопка **«Список»** — принудительно обновить список гильдий с сервера.

### История боёв (кнопка 📚)

- **💾 Экспорт** — сохраняет базу Арены и Гранд-Арены в единый JSON-файл `hwh_arena_backup_YYYY-MM-DD.json`.
- **📂 Импорт** — загружает базу из файла (дубликаты по `replayId` пропускаются). Поддерживаются как новый формат (Арена + ГА), так и старые (только Арена).
- **🔄 Загрузить с сервера** — запрашивает историю через `battleGetByType` для Арены и Гранд-Арены, фильтрует только ваши атаки, считает вероятность и сохраняет в БД. Уже посчитанные реплеи запоминаются и пропускаются при повторных запусках.

## Как это работает

### Бой

1. Запрашивает текущую пачку (`teamGetAll`, `teamGetFavor`, `team_getBanners`, `userGetInfo`).
2. Определяет флаг — из сохранённой пачки или автоматически подбирает лучший по цветам.
3. Ищет соперника (`arenaFindEnemies` / `grandFindEnemies`):
   - отсеивает согильдийцев и дружественные гильдии;
   - проверяет зону досягаемости (`arenaCheckTargetRange` / `grandCheckTargetRange`);
   - при отсутствии подходящих — обновляет список (до 10 попыток).
4. Если включён автоподбор — ищет лучшую пачку в IndexedDB по `probability`.
5. Отправляет атаку (`arenaAttack` / `grandAttack`).
6. Считает `probability` (вероятность победы) прошедшего боя (5 симуляций в фоне, не блокируя UI).
7. Сохраняет бой в БД, если `probability ≥ 0.6`.
8. В фоне подгружает свежую историю с сервера (1 страница).
9. Показывает результат и обновляет место.

### Импорт истории

1. Запрашивает `battleGetByType({ type: 'arena'|'grand', limit: 20, offset: N })` постранично.
2. Для каждой записи проверяет `userId === ваш ID` — только ваши атаки.
3. Пропускает уже сохранённые `replayId` (проверка по обеим БД).
4. Пропускает реплеи, которые уже считались в прошлые разы (список `seenReplays` в `localStorage`).
5. Для новой записи считает вероятность победы (5 симуляций `Calc`) с живым таймером в статусе.
6. Если вероятность < 0.6 — пропускает (но запоминает как обработанный).
7. Иначе — сохраняет в IndexedDB.

### Автоподбор пачки (Арена)

1. Берёт все записи из IndexedDB (Арена).
2. Ищет точное совпадение пачки защитника (`defenderPack` + `defenderPet`).
3. Если точных нет — ищет похожие (≥ 80% совпадения героев, тот же питомец).
4. Группирует найденные записи по вашей пачке атакующего.
5. Считает вероятность победы по каждой группе.
6. Возвращает топ-5 пачек, отсортированных по вероятности.

### Автоподбор пачек (Гранд-Арена)

1. Для каждой видимой пачки защиты ищет точные/похожие матчи в истории ГА.
2. Для каждой защиты выбирает лучшую пачку атакующего.
3. Жадно отбирает до 3 пачек без пересечения героев, остальные места добивает текущей пачкой.

### Автосмена защиты ГА

1. Читает текущую защиту (`arenaGetAll`, `teamGetFavor`, `team_getBanners`).
2. Случайным образом переставляет три пачки (герои + питомцы + флаги).
3. Отправляет `grandSetHeroes` с новой расстановкой.
4. Повторяет каждые 15 секунд, пока включена галочка в настройках.
5. Автозапуск при загрузке игры с ретраями (ждёт готовности меню HWH).

## Хранение данных

- **IndexedDB**:
  - `HWHOneArenaBattle` → `battles` — записи о боях Арены, включая `probability`.
  - `HWHOneArenaBattle_Grand` → `grandBattles` — записи о боях Гранд-Арены.
- **localStorage**:
  - `HWHOneArenaBattle.settings` — настройки авто-боя;
  - `HWHOneArenaBattle.friendlyClans` — список дружественных гильдий;
  - `HWHOneArenaBattle.clanListCache` — кэш списка гильдий (TTL 24 ч);
  - `HWHOneArenaBattle.lastPrune` — дата последней автоочистки;
  - `HWHOneArenaBattle.seenReplays` — последние 50 обработанных `replayId` при импорте с сервера.
- **Автоочистка**: записи старше **120 дней** удаляются раз в сутки при следующем запуске.
