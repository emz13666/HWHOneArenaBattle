# HWHOneArenaBattle

Расширение для [HeroWarsHelper](https://greasyfork.org/ru/scripts/450693-herowarshelper) (HWH), которое проводит **один бой на Арене** текущей пачкой против **любого предложенного соперника**, кроме согильдийцев.

## Возможности

- 🎯 **Один бой на Арене** — берёт текущую пачку (герои + питомец + favor + баннеры) и атакует первого подходящего соперника.
- 🚫 **Исключает согильдийцев** — если все предложенные соперники из вашей гильдии, список автоматически обновляется (до 10 раз).
- 🔄 **Обновление списка** — повторный вызов `arenaFindEnemies` с паузой 1.5 сек между попытками.
- ✅ **Интеграция в HWH**:
  - галочка **«Провести 1 бой на арене»** в форме **«Сделать всё»**;
  - кнопка **«Провести 1 бой на арене»** в меню **«Действия»**.
- 📊 Прогресс и результат боя показываются в статусной строке HWH.

## Установка

1. Установите [HeroWarsHelper](https://greasyfork.org/ru/scripts/450693-herowarshelper) (обязательно, без него расширение не работает).
2. Установите [HWHOneArenaBattle](https://raw.githubusercontent.com/emz13666/HWHOneArenaBattle/main/HWHOneArenaBattle.user.js) через Tampermonkey / Violentmonkey / Greasemonkey.
3. Откройте игру Hero Wars.

## Использование

### Через меню «Действия»

1. Откройте панель HWH.
2. Нажмите **«Действия»**.
3. Выберите **«Провести 1 бой на арене»**.

### Через «Сделать всё»

1. Откройте панель HWH.
2. Нажмите **«Сделать все»**.
3. Поставьте галочку **«Провести 1 бой на арене»**.
4. Нажмите **«Погнали!»**.

## Как это работает

1. Запрашивает текущую пачку для Арены (`teamGetAll`, `teamGetFavor`, `userGetInfo`).
2. Запрашивает список соперников (`arenaFindEnemies`).
3. Отсеивает согильдийцев (сравнение `user.clanId` с вашим `clanId`).
4. Проверяет зону досягаемости (`arenaCheckTargetRange`).
5. Если подходящих нет — обновляет список (до 10 попыток, пауза 1.5 сек).
6. Отправляет бой (`arenaAttack`) с текущей пачкой.
7. Показывает результат: победа/поражение и изменение места.
