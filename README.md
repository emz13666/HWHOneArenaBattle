# HWHOneArenaBattle

Расширение для [HeroWarsHelper](https://greasyfork.org/ru/scripts/450693-herowarshelper) (HWH), которое проводит бои на **Арене** и **Гранд-Арене**, ведёт историю боёв в IndexedDB, считает вероятность победы и **автоматически подбирает лучшую пачку атаки** из накопленной статистики.

## Возможности

### Бои

- ⚔️ **Один бой на Арене** — берёт текущую пачку (герои + питомец + favor + флаги) и атакует первого подходящего соперника.
- 🛡️ **Один бой на Гранд-Арене** — три пачки, три флага, атака одного соперника.
- 🚫 **Фильтр дружественных гильдий** — не атакует согильдийцев и гильдии из вашего списка.
- 🔄 **Автопоиск соперника** — до 10 попыток обновления списка с паузой 1.5 сек.
- 🎚️ **Опциональный фильтр** — «атаковать только если не было атак за сегодня» (отдельно для Арены и ГА).

### История боёв и автоподбор пачки

- 📚 **История боёв в IndexedDB** — каждый бой после атаки автоматически сохраняется (если вероятность ≥ 60%).
- 🎲 **Симуляция вероятности** — 10 прогонов боя через `Calc` со случайным seed, результат — доля побед (`simProbability`).
- 🤖 **Автовыбор лучшей пачки** — перед атакой ищет в истории пачки, которые бились против текущего защитника, и выбирает с наибольшей `simProbability`.
  - **Точный матч** — защитник совпал по составу и питомцу.
  - **Фолбэк ≥ 80%** — 4 из 5 героев совпали и тот же питомец.
- 💾 **Экспорт / импорт базы** — перенос истории между браузерами или ПК через JSON-файл.
- 🔄 **Загрузка истории с сервера** — через `battleGetByType` подтягивает прошедшие бои (только ваши атаки), считает вероятность и сохраняет в БД.
- 🧹 **Автоочистка** — записи старше 120 дней удаляются раз в сутки.

## Установка

1. Установите [HeroWarsHelper](https://greasyfork.org/ru/scripts/450693-herowarshelper) (обязательно, без него расширение не работает).
2. Установите [HWHOneArenaBattle](https://raw.githubusercontent.com/emz13666/HWHOneArenaBattle/main/HWHOneArenaBattle.user.js) через Tampermonkey / Violentmonkey / Greasemonkey.
3. Откройте игру Hero Wars.

## Использование

### Бой через меню «Действия»

1. Откройте панель HWH.
2. Нажмите **«Действия»**.
3. Выберите **«Провести 1 бой на Арене»** или **«Провести 1 бой на Гранд-Арене»**.

### Бой через «Сделать всё»

1. Откройте панель HWH.
2. Нажмите **«Сделать все»**.
3. Поставьте галочки на нужных действиях.
4. Нажмите **«Погнали!»**.

### Настройки авто-боя (кнопка ⚙️)

- **Арена: атаковать только если не было атак за сегодня** — пропускает бой, если попытки уже тратились.
- **Гранд-Арена: атаковать только если не было атак за сегодня** — то же для ГА.
- **Не атаковать дружественные гильдии** — включает фильтр из списка 🌐.
- **При автоатаке на арене искать лучшую пачку в истории боёв** — включает автоподбор пачки по `simProbability`.

### Дружественные гильдии (кнопка 🌐)

- Список всех гильдий из топ-лиг (кэш на 24 часа).
- Отметьте галочками те, которые не нужно атаковать.
- Кнопка **«Список»** — принудительно обновить список гильдий с сервера.

### История Арены (кнопка 📚)

- **💾 Экспорт** — сохраняет всю базу в JSON-файл `hwh_arena_backup_YYYY-MM-DD.json`.
- **📂 Импорт** — загружает базу из файла (дубликаты по `replayId` пропускаются).
- **🔄 Загрузить с сервера** — запрашивает историю через `battleGetByType`, фильтрует только ваши атаки, считает вероятность и сохраняет в БД.

## Как это работает

### Бой

1. Запрашивает текущую пачку (`teamGetAll`, `teamGetFavor`, `team_getBanners`, `userGetInfo`).
2. Определяет флаг — из сохранённой пачки или автоматически лучший.
3. Ищет соперника (`arenaFindEnemies` / `grandFindEnemies`):
   - отсеивает согильдийцев и дружественные гильдии;
   - проверяет зону досягаемости (`arenaCheckTargetRange` / `grandCheckTargetRange`);
   - при отсутствии подходящих — обновляет список (до 10 попыток).
4. Если включён автоподбор — ищет лучшую пачку в IndexedDB по `simProbability`.
5. Отправляет атаку (`arenaAttack` / `grandAttack`).
6. Считает `probability` прошедшего боя (10 симуляций).
7. Сохраняет бой в БД, если `probability ≥ 0.6`.
8. Показывает результат и обновляет место.

### Импорт истории

1. Запрашивает `battleGetByType({ type: 'arena', limit: 20, offset: N })` постранично.
2. Для каждой записи проверяет `userId === ваш ID` — только ваши атаки.
3. Пропускает уже сохранённые `replayId`.
4. Для новой записи считает `probability` (10 симуляций `Calc`).
5. Если `probability < 0.6` — пропускает.
6. Иначе — сохраняет в IndexedDB.

### Автоподбор пачки

1. Берёт все записи из IndexedDB.
2. Ищет точное совпадение пачки защитника (`defenderPack` + `defenderPet`).
3. Если точных нет — ищет похожие (≥ 80% совпадения героев, тот же питомец).
4. Группирует найденные записи по вашей пачке атакующего.
5. Считает среднее `simProbability` по каждой группе.
6. Возвращает топ-5 пачек, отсортированных по вероятности.

## Хранение данных

- **IndexedDB** (`HWHOneArenaBattle` → `battles`): записи о боях, включая `simProbability`.
- **localStorage**:
  - `HWHOneArenaBattle.settings` — настройки авто-боя;
  - `HWHOneArenaBattle.friendlyClans` — список дружественных гильдий;
  - `HWHOneArenaBattle.clanListCache` — кэш списка гильдий (TTL 24 ч);
  - `HWHOneArenaBattle.lastPrune` — дата последней автоочистки.
- **Автоочистка**: записи старше **120 дней** удаляются раз в сутки при следующем запуске.
